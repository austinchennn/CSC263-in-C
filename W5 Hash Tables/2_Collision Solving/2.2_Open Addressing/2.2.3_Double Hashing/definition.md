## Double Hashing（双重哈希）— 定义

- 探测函数：`probe(k, i) = (h₁(k) + i·h₂(k)) mod m`，i = 0, 1, 2, ...
- 用**第二个哈希函数 h₂** 算出探测步长，步长依赖 key
- 本实现：
  - `h₁(k) = k mod m`
  - `h₂(k) = 1 + (k mod (m−1))`，取值范围 [1, m−1]

### 探测序列例子

- m = 13，插入 k = 27：h₁(27) = 1，h₂(27) = 1 + (27 mod 12) = 1 + 3 = 4
  - 探测序列：T[1], T[5], T[9], T[0], T[4], ...（每次 +4，环绕）
- 插入 k = 14：h₁(14) = 1，h₂(14) = 1 + (14 mod 12) = 3
  - 探测序列：T[1], T[4], T[7], T[10], ...（每次 +3）
- 注意 27 和 14 虽然 h₁ 相同，探测序列却**不一样** → 没有 secondary clustering

### 对 h₂ 的约束

- **h₂(k) 必须与 m 互质**，否则探测序列只能覆盖 `m / gcd(m, h₂(k))` 个 slot，可能找不到空位
- 简单保证方式：**m 取素数** → 任何 1 ≤ h₂(k) ≤ m−1 都与 m 互质
- h₂(k) 不能等于 0（否则原地打转）——所以上面用 `1 + (...)`
- 当 gcd(h₂(k), m) = 1 时，探测序列会遍历全部 m 个 slot，一定能找到空位（只要表没满）

### 为什么最好

- Linear / Quadratic 的探测序列只由 h(k) 决定 → 只有 **m 种**不同的探测序列
- Double Hashing 的序列由 (h₁(k), h₂(k)) 决定 → 约 **m² 种**，最接近理论上的 uniform hashing（SUHA 在开放定址下的对应版本）
