## Linear Probing（线性探测）— 定义

- 探测函数：`probe(k, i) = (h(k) + i) mod m`，i = 0, 1, 2, ...
- 探测序列：`h(k), h(k)+1, h(k)+2, ...`，从 h(k) 开始逐格向后，到数组末尾再环绕回 0
- 只用到一个哈希函数 h，是三种方式里最简单的；内存访问是顺序的，对 CPU cache 友好

### 探测序列例子

- m = 13，h(k) = k mod 13
- 插入 k = 18：h(18) = 5
  - 若 T[5] 被占：查 T[6]
  - 若 T[6] 也被占：查 T[7]……直到找到一个 EMPTY 或 DELETED

### Primary Clustering（一次聚集）

- 现象：数组里会形成一段段**连续被占用的 slot**（cluster），而且长的 cluster 增长得更快
- 原因：任何 h(k) 落在某个 cluster 内部（或紧挨着）的 key，最终都会被放到这个 cluster 的**尾部**，使 cluster 更长
- 后果：cluster 越长，落进去的 key 需要的探测次数越多 —— 即使整体 α 不高，局部聚集也会拖慢平均性能
- 一个 cluster 被合并/加长的概率正比于它的长度 → 富者愈富

### 能否一定找到空位

- 能。探测序列 `h(k), h(k)+1, ..., h(k)+m-1` 恰好遍历全部 m 个 slot
- 只要表没满（α < 1），一定能探测到一个非 OCCUPIED 的 slot
