## Disjoint Set（ADT）— 定义

- Disjoint Sets 要解决的问题：如何维护一组元素的**划分（partition）**，把这些元素分成若干个互不重叠（disjoint）的组，并支持快速判断"x 和 y 是否属于同一组"以及"合并两个组"——例如后续课程中 Kruskal 最小生成树算法就依赖这一结构
- Disjoint Set 是一个**抽象数据类型（ADT, Abstract Data Type）**：只规定了一组对外暴露的操作接口，并不限定底层要用哪种数据结构实现
- 对象：一组非空、两两不相交的集合 S = {S1, S2, ..., Sk}
  - 每个集合都由其中一个唯一的元素标识，称为该集合的**代表元（representative）**
- 操作
  - `MakeSet(DS, v)` — 给定一个尚不属于任何集合的元素 v，创建一个新集合 {v}；新加入的元素就是这个新集合的代表元
  - `FindSet(DS, x)` — 返回包含 x 的集合的代表元
    - NOTE：我们已经知道 x 属于哪个集合，只是需要找出这个集合的代表元
  - `Union(DS, x, y)` — 给定两个元素 x 和 y，合并它们各自所在的集合；新集合的代表元可能是原来两个代表元中的一个，可能是 x 或 y，也可能是完全不同的其他元素
    - NOTE：如果 x 和 y 本来就属于同一个集合，这次操作不产生任何效果
