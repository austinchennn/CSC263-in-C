## QuickSort / Randomized QuickSort — Implementation（实现）

### PARTITION

- 实现（子数组下标范围为 [p, r]，1-indexed）
  ```
  PARTITION(A, p, r):
  1  x = A[r]                        # 选取子数组最后一个元素作为 pivot
  2  i = p − 1                       # i 指向"≤ x 区域"的最后一个位置，初始为空区域
  3  for j = p to r − 1               # j 从左到右逐个扫描剩余元素
  4      if A[j] ≤ x                 # 若当前元素不大于 pivot
  5          i = i + 1               # 扩大"≤ x 区域"一格
  6          exchange A[i] with A[j] # 把该元素换入"≤ x 区域"末尾
  7  exchange A[i + 1] with A[r]     # 循环结束后，把 pivot 换到"≤ x 区域"紧后面，即其最终排序位置
  8  return i + 1                    # 返回 pivot 最终所在的下标
  ```
- 不变量：在 for 循环执行过程中，数组被划分为三部分
  - `A[p..i]`：已确定 ≤ x 的区域
  - `A[i+1..j-1]`：已确定 > x 的区域
  - `A[j..r-1]`：尚未处理（unrestricted）的区域
  - `A[r]`：pivot x 本身

#### 示例（Worked Trace）

- 对数组 A = [2, 8, 7, 1, 3, 5, 6, 4]（p = 1, r = 8）调用 `PARTITION(A, 1, 8)`
- pivot 取 x = A[r] = 4
- j 从左到右扫描 A[1..7]：
  - j=1：A[1]=2 ≤ 4，i 从 0 增为 1，与自身交换（无变化）
  - j=2：A[2]=8 > 4，跳过
  - j=3：A[3]=7 > 4，跳过
  - j=4：A[4]=1 ≤ 4，i 增为 2，交换 A[2] 与 A[4]（8 与 1 互换）→ [2, 1, 7, 8, 3, 5, 6, 4]
  - j=5：A[5]=3 ≤ 4，i 增为 3，交换 A[3] 与 A[5]（7 与 3 互换）→ [2, 1, 3, 8, 7, 5, 6, 4]
  - j=6：A[6]=5 > 4，跳过
  - j=7：A[7]=6 > 4，跳过
- 循环结束后，交换 A[i+1]=A[4] 与 A[r]=A[8]（8 与 4 互换）→ [2, 1, 3, 4, 7, 5, 6, 8]
- 返回 i+1 = 4：pivot 4 落在其最终排序位置（下标 4），左侧 [2,1,3] 均 ≤ 4，右侧 [7,5,6,8] 均 > 4
- 最坏情况运行时间：Θ(n)，其中 n = r − p + 1（一次遍历子数组）

### Worst-Case Running Time

- 分析方法：统计 QuickSort 整个执行过程中 Line #4（`if A[j] ≤ x`）被执行的次数，以此作为运行时间的度量
  - 每个元素至多被选为一次 pivot
  - 在每一次递归调用中，子数组内的元素只会与该次调用的 pivot 比较
  - 一个元素一旦充当过 pivot，之后就不会再与任何元素比较
- NOTE：由此可得，数组中任意一对元素 (a, b) 至多被比较一次
- 比较次数的上界 = 所有元素对的个数：
  ```
  Total #comparisons ≤ Total #pairs = C(n, 2) = n(n − 1) / 2
  ```
- 因此 T(n) ∈ O(n²)

### Average-Case Running Time — 期望比较次数推导

- 关键定理：zi 与 zj 会被 QuickSort 比较，当且仅当在 {zi, zi+1, zi+2, ..., zj} 这些元素中，其中之一（zi 或 zj）是第一个被选为 pivot 的元素
  - NOTE：源材料直接给出 Pr(zi 与 zj 被比较) = 2/(j − i + 1)（对应"在 j − i + 1 个候选者中，zi 或 zj 两者之一最先被选中"的概率），但并未在讲义中展开该概率本身的证明，这里按原始推导直接使用
- 推导步骤：
  ```
  E[t_n] = Σ_{i=1}^{n} Σ_{j=i+1}^{n} Pr(zi 与 zj 被比较)

         = Σ_{i=1}^{n} Σ_{j=i+1}^{n} 2 / (j − i + 1)

         = 2(n+1) · Σ_{k=1}^{n−1} 1/(k+1) − 2(n − 1)

         ∈ Θ(n log n)
  ```
  - 第一步：把总比较次数的期望，拆分成对所有元素对 (zi, zj)（i < j）分别求"是否被比较"的期望之和
  - 第二步：代入关键定理给出的比较概率 2/(j − i + 1)
  - 第三步：交换/重新整理求和顺序，把内层对 j 的求和转化为调和级数形式 Σ 1/(k+1)
  - 第四步：调和级数 Σ_{k=1}^{n−1} 1/(k+1) ∈ Θ(log n)，代入后整体为 Θ(n log n)
- 结论：QuickSort 的 Average-Case（及 Randomized QuickSort 的 Expected）运行时间为 Θ(n log n)
